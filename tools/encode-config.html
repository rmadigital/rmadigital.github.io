เข้ารหัสลิงก์ Google Sheet

ใช้เฉพาะเครื่องทีมงาน ไม่ต้องคัดลอกไฟล์นี้ไปเครื่องบูธ

  1. เปิด index.html ด้วยโปรแกรมแก้ไขโค้ด แล้วค้นหาคำว่า const REMOTE_SECRET = "";
  2. วางค่าที่ได้ไว้ระหว่างเครื่องหมายคำพูด เช่น const REMOTE_SECRET = "ค่าที่ได้";
  3. ทำแบบเดียวกันใน result.html (หน้า Export/Report สำหรับทีมงาน)
  4. บันทึกไฟล์ แล้วคัดลอก index.html ไปทุกเครื่องในบูธ (result.html เก็บไว้ที่เครื่องทีมงาน)
